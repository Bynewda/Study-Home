# 논결 (NONGYEOL) — 변리사 2차 수험실

변리사 2차 시험 준비를 1순위, 대학 학업을 2순위로 두는 개인 학습 공간입니다. (슬로건: 쟁점을 세우고, 답안으로 증명하다.)
첨부 기획 보고서(2026-11-01)의 **P0(매일 쓸 첫 운영 버전)** 범위를 모두 구현했습니다.

## 바로 시작하기

1. **`홈페이지 열기.bat`** 파일을 더블클릭하세요. 브라우저에서 `http://localhost:8090/` 주소로 바로 열려 주소창에 윈도우 계정명·폴더 경로가 노출되지 않습니다. (`index.html` 직접 더블클릭도 동작합니다.)
2. 설치·별도 설정이 필요 없으며 브라우저에서 바로 동작합니다.
3. 처음 열면 안내 창이 나옵니다. "시작하기"를 누르면 됩니다.

> 자주 쓰려면 `홈페이지 열기.bat`의 바로가기를 바탕화면이나 작업표시줄에 고정해 두거나, `http://localhost:8090/`을 북마크해 두세요.

## 담긴 기능 (기획 보고서 대응)

| 메뉴 | 내용 | 보고서 |
|---|---|---|
| 오늘의 수험 | 핵심 과업 3개, 확보 시간·이행률·복습·학업 지표, 공부 시작 타이머 | 6·7쪽 |
| 주간 계획 | 목표/확보/미확보 표시, 시간표(데스크톱)+일간 목록(모바일), 충돌 경고 | 8·9쪽 |
| 과업 | 과목·중요도·마감·예상 시간 관리 | 18쪽 |
| 실전 답안과 GS | 문항별 배점·득점, 평가자 구분, 감점 분류, 재작성 추적 | 10쪽 |
| 단권화 노트 | 과목›단원›쟁점 경로, 원문 근거, 상태, 검색·필터, 자동 저장 | 11쪽 |
| 복습 | 회상→확인→자기평가, 간격 규칙 공개, 초안/미검토 구분 | 12쪽 |
| 대학 학업 | 수강 과목, 과제(작성≠제출 구분), 과목별 출결 규칙 | 13쪽 |
| 기록과 회고 | 4주 계획 vs 실제, 감점 원인 집계, 주간 회고 | 3·7쪽 |
| 설정과 백업 | 시험일(공식 확인 후 입력), 테마, JSON 백업/복원 | 17·19쪽 |

## 데이터 저장과 백업 (중요)

- 모든 기록은 **이 브라우저 안(localStorage)**에 자동 저장됩니다.
- 보고서 경고대로, 브라우저 저장소 하나에만 1년치를 맡기면 안 됩니다.
  **[설정과 백업] → "JSON 백업 내보내기"로 월 1회 이상 백업**하세요.
- 다른 기기·브라우저로 옮기거나 복구할 때는 "백업 가져오기"를 씁니다.
- 브라우저 데이터를 지우면 기록도 사라지므로 백업 파일을 안전한 곳에 보관하세요.

## 설계 메모

- 시험일은 공식 공고 확인 후에만 입력하며, 확인 전에는 임의 D-Day를 만들지 않습니다.
- 계획 블록과 실제 공부 세션을 분리해, 계획을 바꿔도 실제 기록이 보존됩니다.
- 색상·타이포·간격·44px 터치 타깃 등 보고서 디자인/접근성 기준을 반영했습니다.
- 로그인·서버 DB·외부 연동·AI는 보고서의 P1/P2 범위로, 이번 버전에는 없습니다.
  (이 구조 위에 나중에 확장할 수 있습니다.)
