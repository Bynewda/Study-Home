# 논결 (NONGYEOL) — 변리사 2차 수험실

변리사 2차 시험 준비를 1순위, 대학 학업을 2순위로 두는 개인 학습 공간입니다. (슬로건: 쟁점을 세우고, 답안으로 증명하다.)
초기 기획 보고서(2026-11-01)의 매일 쓰는 운영 기능에서 출발해, 이후 **강의 학습(인강)·대학 LearnUs 연동·클라우드 동기화·AI 도구**까지 확장했습니다. 각 기능의 실제 활성 조건은 아래 "기능 상태"를 참고하세요.

## 바로 시작하기

1. **`홈페이지 열기.bat`** 파일을 더블클릭하세요. 브라우저에서 `http://localhost:8090/` 주소로 바로 열려 주소창에 윈도우 계정명·폴더 경로가 노출되지 않습니다. (`index.html` 직접 더블클릭도 동작합니다.)
2. 설치·별도 설정이 필요 없으며 브라우저에서 바로 동작합니다.
3. 처음 열면 안내 창이 나옵니다. "시작하기"를 누르면 됩니다.

> 자주 쓰려면 `홈페이지 열기.bat`의 바로가기를 바탕화면이나 작업표시줄에 고정해 두거나, `http://localhost:8090/`을 북마크해 두세요.

## 기능 상태 (구현됨 / 설정 필요 / 검증 안 됨)

| 기능 | 상태 | 설명 |
|---|---|---|
| 로컬 저장 | **기본 활성** | 접속 주소(출처)별로 분리되는 브라우저 저장소입니다. 자동 클라우드 백업이 아닙니다. |
| 클라우드 동기화 (Firebase) | **설정 시 활성** | `js/firebase-config.js`에 설정값을 넣으면 구글 로그인 후 기기 간 실시간 동기화. 동시 편집은 레코드 단위로 병합하고, 충돌 시 직전 상태를 설정 > 백업의 "충돌 백업"에 보관합니다. 다중 기기 동시 편집의 장기 안정성은 실사용으로 더 검증이 필요합니다. |
| LearnUs 자동 수집 | **확장·로그인 조건부** | 전용 브라우저 확장과 LearnUs 로그인 세션이 필요합니다. 비밀번호를 저장하지 않습니다. 실제 계정에서의 데이터 정확도는 사용하며 확인하세요. |
| AI 도구 | **키 설정 조건부** | 사용할 모델의 API 키를 직접 입력해야 동작합니다. 질문에 첨부한 문맥은 선택한 AI 제공사로 전송됩니다. 민감 정보는 넣지 마세요. 키·대화는 기기 로컬에만 저장(클라우드 동기화 대상 아님)됩니다. |

## 데이터 저장과 백업 (중요)

- 모든 기록은 **이 브라우저 안(localStorage)**에 자동 저장됩니다.
- ⚠️ **저장소는 접속 주소(출처)마다 분리됩니다.** `file://`(파일 직접 열기)·`localhost`·로컬 IP·GitHub/Netlify 배포 주소는 서로 다른 저장소입니다. 기록이 안 보이면 지웠다기보다 **다른 주소의 저장소에 있을 가능성**이 큽니다. 평소 쓰는 주소 하나를 정해 두세요. (주소가 아닌 곳에서 열면 앱이 1회 안내합니다.)
- 브라우저 저장소 하나에만 1년치를 맡기지 말고 **[설정과 데이터] → "JSON 백업 내보내기"로 월 1회 이상 백업**하세요.
- 다른 기기·브라우저로 옮기거나 복구할 때는 "백업 가져오기"를 씁니다. 여러 기기에서 쓰려면 Firebase 동기화(설정 시)를 켜는 편이 편합니다.
- 브라우저 데이터를 지우면 기록도 사라지므로 백업 파일을 안전한 곳에 보관하세요.
- **지난·완료 과제와 오래된 공지는 삭제되지 않고 보관함으로 이동**해 기록이 보존됩니다(중요·고정 공지는 계속 노출). 영구 삭제는 직접 확인 시에만 됩니다.

## 설계 메모

- 시험일은 공식 공고 확인 후에만 입력하며, 확인 전에는 임의 D-Day를 만들지 않습니다.
- 계획 블록과 실제 공부 세션을 분리해, 계획을 바꿔도 실제 기록이 보존됩니다.
- 색상·타이포·간격·44px 터치 타깃 등 디자인/접근성 기준을 반영했습니다.
- 구글 로그인·클라우드 동기화·LearnUs 연동·AI는 **위 "기능 상태" 표의 조건에서만** 동작합니다. 설정 전에는 로컬 저장만으로 평소처럼 쓸 수 있습니다.
